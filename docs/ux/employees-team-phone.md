# UX: Team на телефоне

Продолжение [employees-team.md](employees-team.md): то же, что на компьютере, руками на телефоне. Английские строки - текст интерфейса.

## 1. Зачем

На телефоне можно было только смотреть сотрудников. Завести сотрудника, поправить его правила, дать ему Shortcut, запустить его работу или поставить на паузу его расписание - только за компьютером. Назначить задачу можно было лишь из открытого чата.

### Путь до результата

- **Вход:** Settings > Team. Или из чипа сотрудника в чате: "Open <имя> in Team" переключает на вкладку Settings и открывает его страницу.
- **Список:** поиск, сотрудники с ролью, числом открытых задач и точкой "работает", строка No employee (если есть Shortcuts без владельца), переключатель Show archived. "+" в шапке - New employee.
- **Страница сотрудника:** портрет, имя, роль, сводка; карандаш (Edit) в шапке. Разделы Shortcuts (Run и переключатель расписания в строке, нажатие открывает редактор, New shortcut), Tasks, About, Conversations, внизу Archive или Restore.
- **Готово:** сотрудник сохранён на компьютере и виден в списке; Shortcut с владельцем запускает задачу, назначенную ему.

Форма - страницы со стрелкой назад, как остальные разделы Settings телефона: на 390 px две колонки не помещаются. Правка - лист на весь экран с Cancel и Save, как редактор Shortcut.

## 2. Что добавляется

| Поверхность | Что появляется |
| --- | --- |
| Settings > Team | Список как выше; "+" New employee; пустой каталог: "No employees yet" и New employee |
| Страница сотрудника | Как выше |
| Лист Edit employee / New employee | Портреты сеткой, Name, Role, About; Save; Cancel со "Discard changes?" если изменено |
| Страница No employee | Shortcuts без владельца; владельца даёт поле Employee в редакторе |
| Редактор Shortcut | Поле Employee: None и активные сотрудники |
| Долгое нажатие на задачу | Пункт "Assign employee..." (или "Change employee...") с меню назначения |
| Меню чипа в чате | "Open <имя> in Team" / "Open Team", как на компьютере |

## 3. Состояния

| Состояние | Что видит | Что делать |
| --- | --- | --- |
| Компьютер недоступен | Сохранение: "Could not save employee. Try again." | Повторить, когда связь вернётся |
| Сотрудник изменён на компьютере во время правки | "Employee changed on your computer. Reload before saving." и Reload employee | Перезагрузить и повторить правку |
| В архиве | Пометка Archived, Run и переключатели неактивны, "Paused while archived" | Restore |
| Нет имени | "Enter a name" у поля | Ввести имя |
| Редактор Shortcut, поле Employee | "Runs start unassigned" / "Runs start assigned to them" / "Paused while archived" | Выбрать сотрудника |

## 4. Переходы

| Из | Событие | В | Что видит |
| --- | --- | --- | --- |
| Settings | Нажал Team | Список | Список |
| Список | Нажал сотрудника | Страница | Страница, Back "Team" |
| Страница | Back или жест назад (Android Back) | Список | Список |
| Страница | Edit | Лист правки | Поля с текущими значениями |
| Лист | Save | Страница | Новые значения |
| Лист | Cancel без изменений | Страница | Ничего не меняется |
| Лист | Cancel с изменениями | Вопрос | "Discard changes?" Keep editing / Discard changes |
| Страница | Archive | Вопрос | "Archive <имя>?" с числом расписаний на паузу |
| Чип в чате | Open <имя> in Team | Страница | Вкладка Settings, его страница |
| Задача | Долгое нажатие > Assign employee... | Меню | Сотрудники, None, Open <имя> in Team |

## 5. Что молчит

Ошибка обновления инструкций ассистента показывается и на телефоне, с Retry: иначе ассистент молча работает по старым правилам.

## 6. Чего намеренно нет

- Отдельной вкладки Team в нижней навигации: четыре вкладки уже заняты, а с командой работают реже, чем с задачами.
- "+" на каждой карточке доски: на телефоне нет наведения, "+" на каждой строке - шум. Назначение - долгим нажатием и в чате.
- "Give to..." в строке Shortcut: владелец меняется в редакторе.
