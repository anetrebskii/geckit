# One-time handoff for an open browser tab

- Request: Tap a link from GeckIt or Slack, complete verification in the tab the assistant already opened, then close the window.
- Checkout: /Users/alex/Projects/mine/geckit, main, permanent checkout.
- Started: 2026-11-19.

## Acceptance conditions

- Open the HTTPS link in a standard desktop or phone browser and see the same conversation-owned tab at its current page, including a login popup opened from it.
- Interact, then press Done or close the viewer. The assistant can continue in the original tab with its current state.
- Reuse, expiry, concurrent claims and foreign tabs cannot expose a tab. A preview fetch does not claim the link.
- Assumption: Send the bearer link only to the intended user in private. A shared channel must not carry it.
