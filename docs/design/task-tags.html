Tags on tasks

Prototype for docs/ux/task-tags.md. Everything is live: right-click a card, use Filters, use the details panel, press the phone's Tags row.

Board

Right-click a card, then Tags. Type to find or create a tag. Point at a tag for its "..." with Rename, Colour and Delete. Cmd+click picks several cards; the picker then applies to all, with a dash where they differ.

Tasks

Open conversation, details panel

The conversation last clicked on the board. The panel on the right, opened by the sidebar button in the head, has Tags above the checklist: remove with x, add with Add tag. The same picker manages tags here.

Phone

Tasks with tags on their rows; the conversation's info with a Tags row that opens the picker as a sheet. Each tag's "..." renames, recolours or deletes it.
