How to export
  1. In Amnezia, create a separate user named GeckIt.
  2. Select your self-hosted server and AmneziaWG.
  3. Choose AmneziaWG native format and save the .conf file.
  4. Import that file here.

Agents use normal networking. GeckIt manages the connection and keeps its keys outside the agent's configuration.
