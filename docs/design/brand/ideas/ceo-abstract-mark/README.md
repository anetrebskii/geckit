# Абстрактный знак GeckIt

Задача знака — обозначить GeckIt как бесплатное рабочее пространство, в котором CEO стартапа подключает ИИ-сотрудника и поручает ему работу.

Принцип — показать подключение одним стыком, заметным в одном цвете. Меньшая форма входит в выемку большей. Просвет повторяет контур стыка и сохраняет обе части различимыми. В полной версии этот рисунок продолжает идею соединения `k` и `I` в надписи.

В выборке встречаются абстрактные эмблемы, персонажи и буквы на цветных плитках. Здесь силуэт держится на выемке и входящем в неё выступе. [Сохранённый лист сравнения из 15 знаков](../round-11-symbol/geckit-competitors.png)

## Проверка по стандарту «Логотип по Лебедеву»

Монохромные и зелёные версии знака и надписи визуально проверены на обоих фонах при высоте 16, 32 и 512 px. На превью знак при 16 и 32 px показан в исходных размерах.

| Проверка | Результат |
| --- | --- |
| 1. Читаемость | В композиции высотой 16 px надпись читается как GeckIt. Знак отдельно букв не содержит. |
| 2. Малый размер | При 16 и 32 px выступ и просвет различимы на обоих фонах. |
| 3. Сходство | Совпадений с формами из сохранённой выборки не видно. |
| 4. Смысл | Меньшая форма входит в выемку большей. |
| 5. Одна идея | Выступ и выемка образуют один стык. |
| 6. Декор | Два контура без подложки и эффектов. Удаление любой части убирает стык. |
| 7. Оригинальность | Силуэт построен вокруг асимметричного стыка. В сравнительной выборке такой формы нет. |
| 8. Шрифт | Взята надпись предыдущего раунда на основе XCharter Bold. Знак немного ниже её прописных букв и читается отдельно за счёт просвета перед `G`. |
| 9. Рисунок | Геометрический знак. При 512 px просвет непрерывен, изломы и скругления различимы. |
| 10. Соответствие | Название, начертание и акцент сохраняют преемственность. Цветное исполнение пересекается с палитрой Tasklet по цветовому семейству. Целевой сегмент взят из текущего бесплатного позиционирования GeckIt. Соответствие будущему платному сегменту неизвестно без его ценового диапазона. |
