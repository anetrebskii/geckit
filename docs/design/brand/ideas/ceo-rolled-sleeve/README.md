# GeckIt. Засучив рукава

Задача: представить бесплатную рабочую среду для CEO стартапа, который поручает работу ИИ-сотруднику. Принцип: один жест должен одновременно принадлежать человеку и интерфейсу. Рука согнута в локте, вместо кулака у неё курсор. Справа от бицепса виден отворот рукава.

## Проверка по стандарту Lebedev Logo

| Тест | Результат |
| --- | --- |
| 1. Читаемость | При высоте композиции 16 px читается GeckIt, прописная I отделена от k. |
| 2. Размер | В 16 px различимы острие и согнутый силуэт, отворот легче различить при 32 px. |
| 3. Сходство | Жест напоминает знакомый эмодзи с бицепсом. Замена кулака курсором меняет силуэт. В сохранённой выборке из 15 марок такой комбинации нет. |
| 4. Смысл | Цифровой сотрудник засучил рукава и берётся за дело. |
| 5. Одна идея | Курсор завершает предплечье, весь знак изображает один жест. |
| 6. Декор | Оба контура нужны: один образует руку с курсором, второй даёт ей рукав. |
| 7. Оригинальность | Собственный рисунок. Совпадений композиции в выборке не найдено. |
| 8. Шрифт | XCharter Bold с интервалами из бренд-кита. Нижний край локтя совпадает с оптической линией текста. |
| 9. Рисунок | У локтя внешний контур скруглён, внутренний образует сгиб. Манжета охватывает плечо. |
| 10. Соответствие | По дизайнерской оценке разговорный жест уместен для доступного инструмента небольшой команды. Сохранено фирменное написание. Для этой концепции выбран монохром. |

Проверены 12 растров: знак и полная композиция при высоте 16, 32 и 512 px в прямом и инверсном исполнении. Понимание образа без подписи у аудитории не проверялось. [Сохранённая выборка марок](../round-11-symbol/geckit-competitors.png)
