# GeckIt. Именная табличка

Задача логотипа: обозначить GeckIt как бесплатное рабочее пространство, в котором CEO стартапа даёт ИИ-сотруднику место в команде и поручает ему работу. Ценовой уровень взят из README проекта.

Принцип: имя исполнителя должно само образовывать знак. Надпись стоит на лицевой стороне сложенной таблички. Один просвет справа показывает сгиб. В компактной версии лицевая сторона сужается до ширины инициала. Буквы вырезаны и принимают цвет фона.

## Проверка по стандарту Lebedev Logo

Сопоставлены сохранённые изображения 15 марок. В выборке повторяются яркие плитки, инициалы и абстрактные эмблемы. Для этой концепции выбран чернильный монохром. [Лист сравнения](../round-11-symbol/geckit-competitors.png)

| Проверка | Результат |
| --- | --- |
| 1. Читаемость | Пройдена. При высоте 16 px читается GeckIt. Между k и прописной I остаётся просвет. |
| 2. Малый размер | Пройдена с ограничением. При высоте 16 px различимы G и правая опора. Сам предмет легче узнать при 32 px. |
| 3. Сходство | Пройдена в пределах выборки. Такой таблички среди 15 знаков нет. Сокращённый вариант без названия также похож на складной указатель. |
| 4. Смысл | Пройдена. У ИИ-сотрудника появилось своё рабочее место. |
| 5. Одна идея | Пройдена. И имя, и силуэт принадлежат одному предмету. |
| 6. Декор | Пройдена. Если убрать правую опору, табличка превращается в наклонную плашку. |
| 7. Оригинальность | Пройдена в пределах выборки. Сохранены буквы из бренд-кита GeckIt. Силуэт разработан для этой надписи. |
| 8. Шрифт | Пройдена. Сохранены засечки XCharter Bold и интервалы бренд-кита. Грани знака дают прописным место сверху и снизу. |
| 9. Рисунок | Пройдена. Передняя грань шире задней опоры, верхний сгиб непрерывен. Видно на растре 512 px. |
| 10. Соответствие | Дизайнерская оценка для текущего бесплатного продукта: пройдена. Обычная складная табличка уместна на рабочем столе стартапа. Преемственность даёт написание GeckIt. |

Проверены 12 растров: название и компактный знак, каждый высотой 16, 32 и 512 px, в прямом и обратном монохроме. Это самостоятельная концепция для рассмотрения. Понимание метафоры основателями не проверялось.
