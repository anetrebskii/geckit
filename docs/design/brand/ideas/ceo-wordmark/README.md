# Логотип GeckIt для CEO стартапов

Задача логотипа — сделать узнаваемым GeckIt как бесплатное рабочее пространство для CEO стартапов, которые подключают ИИ-сотрудника, поручают ему задачи и принимают результат.

Одна связь между буквами показывает подключение и сохраняется в монохроме.

Верхний штрих `k` входит в стойку `I`. Буква `I` сохраняет обе засечки, а просвет между нижними штрихами помогает прочитать обе буквы. Основа из предыдущего комплекта XCharter Bold сохраняет привычное написание GeckIt.

В сравнении использован сохранённый [лист из 15 знаков](../round-11-symbol/geckit-competitors.png). В нём встречаются абстрактные эмблемы, персонажи и буквы в цветных плитках. Сцепление двух букв выделяется в этой выборке и остаётся видимым в одном цвете.

## Проверка по стандарту «Логотип по Лебедеву»

Обе версии отрисованы и визуально проверены при высоте 16, 32 и 512 px. На превью образцы 16 и 32 px показаны в исходных размерах.

| Проверка | Результат |
| --- | --- |
| 1. Читаемость | GeckIt читается при 16 px. Две засечки `I` различимы. |
| 2. Малый размер | При 16 и 32 px соединение штрихов сохраняется, нижний просвет виден в обеих версиях. |
| 3. Сходство | Совпадений силуэта надписи с сохранённой выборкой не обнаружено. |
| 4. Смысл | Один штрих присоединяет `I` к слову. |
| 5. Одна идея | Подключение выражено одной связью. |
| 6. Декор | SVG содержит только контуры букв. |
| 7. Оригинальность | Рисунок предыдущего GeckIt сохранён, связка `kI` сделана для этого написания. Заимствований из выборки не обнаружено. |
| 8. Шрифт | Штрих соединения продолжает засечку `k`. Нижняя засечка `k` укорочена, чтобы оставить просвет у `I`. |
| 9. Рисунок | Нефигуративный знак. На 512 px контуры соединяются без щели. |
| 10. Соответствие | Проверена преемственность с XCharter Bold. Для концепта использованы два монохромных начертания. Соответствие будущему платному сегменту неизвестно, для проверки нужно знать целевой ценовой уровень. |
