# GeckIt geometric mark

Identify GeckIt, a free AI workspace for startup CEOs adding capacity to an existing team. The same rectangle represents each contributor. Two sit on a baseline, and the third tilts into the space between them.

[Preview](preview.png) · [Logo](logo-ink.svg) · [Reversed logo](logo-white.svg) · [Mark](mark-ink.svg) · [Reversed mark](mark-white.svg)

**Verdict after review.** Retire this proposal. The arrangement is legible, but an incoming teammate and a departing one have the same silhouette. The saved Beam.ai mark already uses a three-bar motif.

## Lebedev Logo checks

| Test | Observation |
| --- | --- |
| 1. Legibility | The name reads GeckIt at 16 px high in both versions. |
| 2. Small sizes | At 16 and 32 px, both gaps and the tilted top edge are visible. |
| 3. Resemblance | Failed. At 16 px it can read as two uprights and a punctuation stroke. Books and a bar chart are also plausible readings. |
| 4. Meaning | Failed. The middle piece stops about 19 units above the baseline on a 72-unit canvas. It could be entering or leaving. Neither reading identifies an AI employee without context. |
| 5. One idea | Position supplies the whole visual difference between the three identical pieces. |
| 6. Filler | Two blocks establish the group, the third supplies the joining gesture. |
| 7. Originality | Failed for category differentiation. Beam.ai uses three inclined bars in the saved comparison. The precise outlines differ, but the shared motif is the identifying feature. |
| 8. Type | The outlined XCharter wordmark keeps the established spacing. The upright blocks echo the verticals in the name. |
| 9. Drawing | All pieces share dimensions, and the middle piece fits upright in the gap. |
| 10. Fit | The existing name and ink colour retain continuity. By design judgment the unadorned mark suits the free workspace. |

The mark alone and with its wordmark were rendered on light and dark backgrounds at heights of 16, 32 and 512 px.
