# Hired chat v3: the tail is the tie

The speech bubble's tail runs on into a tie, and a green jacket frames it with its lapels. One shape, one trick: the conversation put on a tie and went to work. Recommended: `a-tail-tie`. `b-tail-tie-knot` (separate knot) breaks the continuity that makes the trick; `v2-before` is the previous version.
