# Running brief

A symbol for GeckIt, the free AI workspace for startup CEOs who want a brief picked up quickly. A folded task card supplies the body of a runner. All assets use the same letter-free drawing.

## Lebedev Logo review

| Check | Observation |
| --- | --- |
| 1. Name legibility | Inapplicable to a symbol with no lettering. It can sit next to the product name on first exposure. |
| 2. Small size | The stride remains visible at 16 px. The corner is easier to identify as folded paper at 32 px. Both polarities were inspected at 16, 32 and 512 px wide. |
| 3. Resemblance | The bent legs recall a running-person pictogram. The document body makes the profile different. |
| 4. Meaning | An assigned brief gets moving. The silhouette communicates action better than the identity of the person or AI doing the work. Audience interpretation is unverified. |
| 5. One idea | The task itself runs. |
| 6. Filler | The fold identifies the card. Both legs establish a stride. |
| 7. Originality | The folded file and running legs are familiar signs. Their combined silhouette differs from the saved 15-mark category sample. |
| 8. Type | The symbol stands alone. Preview labels are outside the mark. |
| 9. Drawing | One knee reaches forward while the trailing foot lifts; the card leans in the direction of travel. |
| 10. Fit | The gesture suits the speed brief. The established green works against ink but is shared in the category. |
