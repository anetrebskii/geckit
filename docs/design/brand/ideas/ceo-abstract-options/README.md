# Варианты абстрактного знака GeckIt

Задача знака — обозначить GeckIt как бесплатное рабочее пространство для CEO стартапов, которые подключают ИИ-сотрудника и поручают ему задачи.

Принцип — передать одно действие геометрией стыка. Во всех вариантах две формы и один просвет между ними. Надпись GeckIt на основе XCharter Bold используется во всех композициях для прямого сравнения.

[Сравнение на одном листе](geckit-options.png)

| Вариант | Идея и результат |
| --- | --- |
| Исходный стык | Выступ расширяется внутри выемки. Рекомендован, потому что форма передаёт подключение через конкретный тип соединения, который сохраняется в силуэте. |
| Прямой паз | Меньшая форма подключается сбоку. Самый близкий вариант к исходному. При 16 px стык ясен, но его прямые углы проще спутать с буквенным знаком. [SVG](geckit-step.svg) |
| Передача задачи | Одна форма подхватывает диагональ другой. Лучше всего показывает движение, но при 16 px диагональ может читаться как пиктограмма перехода. [SVG](geckit-handoff.svg) |
| Место в команде | Верхняя форма опускается в подготовленную выемку. Хорошо передаёт присоединение к команде. Нижний контур может напоминать лоток. [SVG](geckit-seat.svg) |

## Проверки по стандарту «Логотип по Лебедеву»

Знаки и композиции отрисованы при высоте 16, 32 и 512 px в тёмном и белом вариантах. Внизу каждого блока на листе видны размеры 16 и 32 px без увеличения. Сравнение с категорией ограничено ранее собранной выборкой. [Лист сравнения из 15 знаков](../round-11-symbol/geckit-competitors.png)

| Проверка | Исходный стык | Прямой паз | Передача задачи | Место в команде |
| --- | --- | --- | --- | --- |
| 1. Читаемость | Название читается в композиции при 16 px. | Читается. | Читается. | Читается. |
| 2. Малый размер | Обе формы и стык различимы. | Прямой паз виден при 16 px. | Щель видна, возникает сходство с переходом. | Верхняя перемычка и просвет различимы при 16 px. |
| 3. Сходство | Совпадения в выборке не видно. | Есть сходство с угловатой монограммой. | Сходство со знаком перехода при 16 px. | Есть сходство с лотком на 32 и 512 px. |
| 4. Смысл | Подключение через стык. | Подключение сбоку. | Подхват задачи. | Место для нового участника. |
| 5. Одна идея | Один стык. | Один паз. | Один диагональный переход. | Одна выемка. |
| 6. Декор | Только две формы. | Только две формы. | Только две формы. | Только две формы. |
| 7. Оригинальность | Асимметричная выемка выделяется в выборке. | Шире распространён ступенчатый силуэт. | Диагональная форма близка к типовым пиктограммам. | Силуэт отличается от знаков выборки, остаётся ассоциация с лотком. |
| 8. Шрифт | Согласован с массой и высотой надписи. | Просвет перед надписью читается, вес знака близок к исходному. | Диагональ добавляет движения, знак не перебивает слово. | Более широкое основание компенсирует низкий силуэт. |
| 9. Рисунок | Геометрия стыка чистая на 512 px. | Контуры паза различимы на 512 px. | Диагональные края разделены на 512 px. | Контуры выемки читаются на 512 px. |
| 10. Соответствие | Сохранены надпись и монохром. | Те же надпись и монохром. | Те же надпись и монохром. | Те же надпись и монохром. |

Соответствие будущему платному сегменту неизвестно без его ценового диапазона.
