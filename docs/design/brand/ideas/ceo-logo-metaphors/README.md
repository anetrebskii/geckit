# Предметные идеи для логотипа GeckIt

Задача логотипа — обозначить GeckIt как бесплатное рабочее пространство для CEO стартапов, которые подключают ИИ-сотрудников, поручают им задачи и управляют работой.

Один предметный образ передаёт одно действие и держится в одном цвете. В качестве основы для всех композиций использована надпись GeckIt на основе XCharter Bold. Исходный стык показан рядом для сравнения.

[Лист с вариантами](geckit-metaphors.png)

- **Взять задачу.** Открытая ладонь подхватывает рабочую карточку. Из трёх новых знаков этот ближе всего к действию в GeckIt: руководитель поручает работу, исполнитель её принимает. [SVG](geckit-handoff.svg)
- **Кресло у стола.** Свободное место для нового участника команды. В малом размере может выглядеть как знак из букв и перекладин. [SVG](geckit-desk.svg)
- **Рычаг управления.** Наклон рукоятки показывает, что человек задаёт ход работы. Сам силуэт напоминает промышленный переключатель. [SVG](geckit-lever.svg)

## Проверки по стандарту «Логотип по Лебедеву»

Знаки отдельно и с надписью отрисованы в монохроме на обоих фонах при высоте 16, 32 и 512 px. На сравнительном листе образцы 16 и 32 px даны в исходных размерах. Сравнение с категорией охватывает сохранённую выборку, в которой встречаются абстрактные эмблемы, персонажи и цветные монограммы. [Лист из 15 знаков](../round-11-symbol/geckit-competitors.png)

| Проверка | Взять задачу | Кресло у стола | Рычаг управления |
| --- | --- | --- | --- |
| 1. Читаемость | Надпись GeckIt читается при 16 px. | Надпись читается при 16 px. | Надпись читается при 16 px. |
| 2. Малый размер | Ладонь и карточка различимы при 16 px. Сгиб карточки лучше читается при 32 px. | Два силуэта остаются раздельными, но при 16 px мебель распознаётся хуже. | Рукоятка различима при 16 px, ось различимее при 32 px. |
| 3. Сходство | Может ассоциироваться с пиктограммой помощи или передачи документа. Совпадений в выборке не видно. | При 16 px напоминает угловатое `T` с дополнительной перекладиной. | Похож на пиктограмму переключателя. Совпадений в выборке не видно. |
| 4. Смысл | Ладонь принимает задачу. | У команды появилось ещё одно место. | Руководитель управляет ходом работы. |
| 5. Одна идея | Принять поручение. | Место для участника. | Управление. |
| 6. Декор | Сгиб отличает рабочий документ от прямоугольника. | Перекладины образуют кресло и стол. | Отверстие показывает ось рычага. |
| 7. Оригинальность | Композиция отличается от знаков выборки. | Самостоятельный рисунок, который теряет предметность при уменьшении. | Самостоятельный рисунок с узнаваемым промышленным силуэтом. |
| 8. Шрифт | Ладонь и карточка сбалансированы с массой надписи. | Прямые перекладины визуально тяжелее букв. | Компактное основание уравновешивает наклон рукоятки рядом с надписью. |
| 9. Рисунок | Силуэт открытой ладони в профиль. Просвет до карточки различим на 512 px. | Кресло помещается под столешницей. Оба контура различимы на 512 px. | Отверстие в месте поворота рукоятки. Контур цельный на 512 px. |
| 10. Соответствие | Сохранены надпись и монохром. | Сохранены надпись и монохром. | Сохранены надпись и монохром. |

Соответствие будущему платному сегменту неизвестно без его ценового диапазона.
