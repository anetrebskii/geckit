# Три варианта логотипа GeckIt

**Задача.** Сделать узнаваемым бесплатное рабочее пространство GeckIt для CEO стартапов, которые подключают ИИ-сотрудника, поручают ему работу и принимают результат.

**Принцип.** Одно действие читается по силуэту. Форма должна сохранять смысл в одном цвете и при уменьшении до 16 px.

**Рекомендация — «Стык».** Выступ точно входит в выемку, как ИИ-сотрудник в рабочий процесс. Стык читается при 16 px и в просмотренной выборке имеет самый отличимый силуэт. «Взять задачу» и «Оттиск» показывают два других момента того же рабочего процесса.

## Двухцветные версии

Текущий зелёный выделяет один элемент в каждом знаке. Графитовый или белый контур задаёт контекст действия. В «Стыке» зелёный получает подключаемая деталь, в «Взять задачу» — карточка, в «Оттиске» — след печати. [Лист двухцветных вариантов](geckit-two-tone.png)

| Вариант | Светлый фон | Тёмный фон |
| --- | --- | --- |
| Стык | [Знак](joint/mark-two-tone-light.svg) · [С надписью](joint/logo-two-tone-light.svg) | [Знак](joint/mark-two-tone-dark.svg) · [С надписью](joint/logo-two-tone-dark.svg) |
| Взять задачу | [Знак](handoff/mark-two-tone-light.svg) · [С надписью](handoff/logo-two-tone-light.svg) | [Знак](handoff/mark-two-tone-dark.svg) · [С надписью](handoff/logo-two-tone-dark.svg) |
| Оттиск | [Знак](imprint/mark-two-tone-light.svg) · [С надписью](imprint/logo-two-tone-light.svg) | [Знак](imprint/mark-two-tone-dark.svg) · [С надписью](imprint/logo-two-tone-dark.svg) |

Двухцветные знаки и композиции проверены при 16, 32 и 512 px на обоих фонах. При 16 px видны оба элемента и просвет между ними. Цвет яснее всего объясняет «Стык»: выделенная деталь буквально входит в нейтральную основу. Зелёный занимает около 45% площади знака, 49% у ладони с карточкой и 28% у оттиска. Двухцветный рисунок снижает визуальное сходство с целиком зелёным знаком Tasklet. Пересечение по цветовому семейству сохраняется. [Бренд-кит Tasklet](https://tasklet.ai/brand)

## Проверки по стандарту «Логотип по Лебедеву»

Каждый знак и его композиция с надписью отрисованы и визуально проверены при 16, 32 и 512 px на светлом и тёмном фоне. Это 72 растра для трёх вариантов в четырёх исполнениях. Образцы 16 и 32 px показаны на листе без увеличения.

Для проверки сходства использована сохранённая выборка из 15 знаков. В ней повторяются геометрические плитки, монограммы и персонажи. Из нового раунда исключена рельсовая стрелка: при 16 px её маршрут превращается в две полосы без предметного смысла. [Лист конкурентов](../round-11-symbol/geckit-competitors.png)

Текущий акцент GeckIt — `#1F8031` для светлого фона и `#4AC85C` для тёмного. Это решение брифа. Tasklet также использует зелёный как основной цвет знака, хотя его оттенок отличается. При строгой проверке различия фирменных цветов пункт 10 для зелёных версий не проходит. Для проверки будущего платного сегмента нужен его ценовой диапазон.
