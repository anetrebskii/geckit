# Design handoff

Behavior: [remote-clients UX](../../docs/ux/remote-clients.md). Architecture: [ITD-001](../../DECISIONS.md), [remote clients](../../docs/remote-clients.md).
Use GeckIt topbar/settings/board/list tokens. Pairing now has two steps: run `geckit pair`, paste code and Connect. No device-name decision, QR, scope picker or second approval. Full grants open the existing Chat workspace in an isolated renderer context with a compact computer selector in the existing toolbar. Its API targets the selected server; the parent local workspace is untouched. Existing scoped grants request pairing again; the reduced viewer is removed. Mobile retains legacy entry. Prototype: actual changed component in the existing browser harness; layout authority is the normal Chat workspace. Alex explicitly requested this reversal on 2026-11-06. Review evidence belongs in docs/reports/simple-remote-control.md.
