# Validation quickstart

1. In `client/`, run `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`; in `mobile/`, `npm run build`.
2. Focused tests create a temporary catalog and provider configs: save/reopen/edit/archive/restore; fail catalog write and guide write separately; reject stale revision; preserve personal global instructions.
3. Fixture integration assigns before dispatch and checks prompt unchanged, reassigns and reads current role, traverses more than ten sources and a huge message, includes hidden/archive, reports unavailable provider/host, and leaves source state untouched.
4. Isolated CLI uses current session identity for role; catalog and memory are read-only. Authenticated Manager tests create/assign with explicit employee and preserve normal policy; reject unknown/archive and unauthorized targets.
5. Browser actual renderer: `http://127.0.0.1:5195/test/browser/employees/viewport.html?width=1440&height=900` using the Vite config under `client/test/browser/employees/`. Use width=1024&height=768 or width=390&height=844&phone=1; theme=dark, large=1 (800 tasks), guide=source and controls=0 are optional. Settings Employees create/edit/cancel/error/retry/archive/restore/avatar; New task assignment; header reassignment; intersect top filter with folder/profile/search; read role/source pages. Native Safari fallback was used because browser bridges were unavailable. This fixture uses actual renderer/preload with synthetic IPC, not a real paired phone or provider.
6. Real provider check, when available: in a second assigned employee session retrieve a known decision from the first without repeating it. Never infer model use from an instruction file, static screenshot or fake provider. Installed guide/source mode, actual paired phone and SSH are separate checks.

Memory pages contain at most 20,000 message characters, ten sources and forty messages; continuation preserves message offsets, including empty messages. Image bodies are omitted from text memory with `attachmentsOmitted`. Manager responses fit below 20,000 serialized characters and may shorten display paths/titles with `metadataTruncated`; exact source IDs and cursors remain. Read the employee profile separately with `employees show`.

Packaged builtin Claude/Codex guide updates are covered by isolated config tests. Source mode updates its own Claude and Codex guides without editing the installed app's global instructions. Codex preserves the project's effective developer instructions alongside the common guide pointer. Restart the development app when no work is active to load main-process changes, then Retry any stale guide error. Results and remaining live checks: [verification.md](verification.md).
