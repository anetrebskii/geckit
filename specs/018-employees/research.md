# Research decisions

1. **Catalog storage:** atomic `employees.json`, owned by main. Existing generic settings writes suppress errors and cannot truthfully distinguish failed save from failed guide update. Revision detects concurrent edits. Assignment uses existing SessionNote metadata plus source root for durable history discovery.
2. **Memory retrieval:** enumerate assigned notes and available provider sessions, including hidden/archived. Read provider history directly without bring/adopt/mark-read side effects. Bounded pages retain source/message/character continuation, source identity and unavailable reason. Reading full history automatically on every turn was rejected by the user.
3. **Instructions:** extend managed `GECKIT.md` generation and preserve existing imports/user text. Development source leaves installed globals alone and writes separate app-data guides. Claude has a generic source CLI pointer; installed Codex app-server schemas confirm developerInstructions on thread start/resume/fork and config/read supplies effective developer_instructions. Merge the baseline with a generic guide pointer and restore it when disabled. Test installed-mode generation in isolated provider config folders and source lifecycle through fake RPC; an isolated native thread-start probe checks field acceptance without inference.
4. **UI:** reuse SettingsDialog list/form, Menu/Picker/Sheet and memoized board/list/phone rows. Store employeeFilter in shared Settings to match approved synchronization. Keep unfiltered sessions for lifecycle/notifications and separately memoize visible sessions.
5. **Portraits:** bundle twelve generated Avataaars 9.x portraits by Pablo Stanley through DiceBear; no runtime service/account or package. Official style documentation identifies free personal/commercial use: https://www.dicebear.com/styles/avataaars/. Artwork license/source is retained in the avatar folder. Version 10 request with transparent background was rejected by API; v9 generation succeeded.
6. **Research delegation:** backend and renderer strict-TypeScript agents independently inspected their owned modules and coordinated one shared contract. Both confirmed `employeeId` naming; renderer does not redefine domain types.
7. **Browser:** supported CUA Chrome and in-app attempts both failed with browser access host unavailable. No browser screenshot or interaction is claimed; prototype exists and required later review is recorded.
