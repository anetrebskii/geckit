# Quickstart

1. Open Settings > Libraries.
2. Check now or wait for automatic checking until a row shows Update ready.
3. Select Apply update. Confirm the progress state, then verify the ready marker disappears while GeckIt stays open.
4. Send a message in a new conversation and verify the new provider handles it. For an active conversation, let the current answer finish and send another message to exercise handoff.
5. Repeat with `?libraries=1&applyFail=1` in the preview to confirm the row remains ready and displays an error.
